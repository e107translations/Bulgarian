# e107 Bulgarian Language Pack

Професионален български езиков пакет за e107 CMS 2.3.x.

Текущата база на превода е **e107 v2.3.10**. Преводът се изготвя наново по официалните английски езикови файлове на e107 и не използва стария български превод като източник.

## Статус

Основният български езиков пакет за **e107 v2.3.10 е завършен**.

Към момента са добавени **137 PHP езикови файла**, както и български runtime overlay за стандартните теми от `e107_themes`.

### Завършено

- всички основни файлове от `e107_languages/English/` имат български еквивалент в `e107_languages/Bulgarian/`;
- основни системни и публични езикови файлове;
- вход, регистрация, контакт, имейл и системни грешки;
- потребителски профили, настройки, разширени полета, класове и публикации;
- възстановяване на парола;
- новини, изпращане на новини, коментари и оценяване;
- търсене, страници, online статус, странициране и версия за печат;
- качване на файлове и обработка на качванията;
- BBCode/renderer помощни текстове;
- Library Manager и mail/form handlers;
- режим за ограничен достъп и временно затворен сайт;
- инсталатор на e107;
- основна администрация и настройки;
- управление на потребители и администратори;
- кеш, задачи по график, мета настройки и известия;
- файлов мениджър, медия, теми, плъгини и системни обновявания;
- всички езикови ресурси на стандартните bundled плъгини от e107 v2.3.10;
- езиковите ресурси и видимите runtime текстове на стандартните bundled теми от e107 v2.3.10.

### Стандартни теми

Езиковите ресурси на стандартните bundled теми от **e107 v2.3.10** са преведени. Допълнително е добавена локализация на видимите текстове, които официалните теми съдържат директно в `theme.xml`, конфигурационни файлове и runtime шаблони.

- `_blank` — публични системни текстове, metadata, layout заглавия, примерни настройки и помощна секция;
- `bootstrap3` — административни настройки, Theme Manager metadata, layout заглавия, accessibility текст, Modern Business heading, Custom Fields и Gallery шаблони;
- `bootstrap5` — публичен/административен езиков файл, Theme Manager metadata, layout заглавия и accessibility текст;
- `voux` — Theme Manager metadata, настройки на темата, навигация, коментари, newsletter форма, footer текстове и новинарски шаблони.

### Локализация на `e107_themes`

Добавен е български runtime overlay на **15 файла** от стандартните теми:

- 2 файла за `_blank`;
- 6 файла за `bootstrap3`;
- 2 файла за `bootstrap5`;
- 5 файла за `voux`.

Локализирани са само текстове, които реално се виждат от потребител или администратор. Запазени са без промяна техническите идентификатори и стойности — имена на layouts, route/URL стойности, plugin зависимости, shortcode имена, CSS класове, theme preference ключове, файлови пътища и други машинно използвани данни.

Файловете `e107_themes/*/install/install.xml` съдържат основно примерни статии, Lorem ipsum, тестови менюта и други начални данни за създаване на демонстрационен сайт. Те умишлено не са част от runtime локализацията, защото представляват примерното съдържание на сайта, а не интерфейс на темата.

За theme overlay-а са извършени:

- `php -l` за всички **8** PHP файла — успешно;
- XML проверка на всичките **4** локализирани `theme.xml` файла — успешно;
- структурно сравнение с официалните `theme.xml` от e107 v2.3.10;
- проверка за запазени plugin зависимости, layouts, custom pages, CSS файлове и theme preference ключове;
- проверка за останали целеви hardcoded английски UI текстове.

## Финална проверка

Финалният QA на основния езиков пакет е извършен спрямо официалните английски езикови ресурси на **e107 v2.3.10**.

Проверено е покритието на **137 PHP езикови файла**:

- **49** основни и административни езикови файла;
- **84** езикови файла на стандартните bundled плъгини;
- **4** езикови файла на стандартните bundled теми.

При разработката и финалната проверка са извършени:

- сравнение на активните `define()` константи с официалните English файлове;
- проверка за липсващи и допълнителни константи;
- проверка за дублирани константи;
- проверка на критичните placeholders, shortcodes, HTML и BBCode маркери;
- проверка и корекция на видим текст в bracket-based линкове, като `[тук]`, `[настройките]` и `[обновяване на базата данни]`;
- уеднаквяване на термина **„Потребителски клас“** за e107 `User class`;
- PHP syntax проверка с `php -l`;
- сравнение на Git blob SHA стойности след груповите промени.

Помощната документация и общите документационни файлове на e107 не са необходими за работата на езиковия пакет и не са част от основния runtime превод.

## Поддръжка

Българската локализация за **e107 v2.3.10** е завършена за основния езиков пакет, bundled плъгините и runtime интерфейса на bundled темите. При следващи версии на e107 трябва да се сравняват новите и променените английски езикови и theme файлове и да се добавят съответните промени в българския превод.
